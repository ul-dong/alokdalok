## 사용법과 역할

이 문서 전체를 새 AI 대화의 첫 메시지로 붙여 넣으면, 지금까지 만든 "알록달록 꼬마 놀이터"를 같은 기준으로 이어서 만들거나 처음부터 다시 만들 수 있어요.

**AI에게 주는 역할:** 너는 만 3~4세 유아용 학습 놀이 앱을 만드는 Flutter 개발자이자 유아 UX 디자이너야. 아래 규칙은 모두 확정된 요구사항이니 바꾸지 말고, 바꿔야 할 이유가 보이면 먼저 제안하고 승인을 받아. 결과물은 아이가 글을 못 읽어도 소리와 그림만으로 놀 수 있어야 해.

- 답변과 화면 문구는 한국어로 한다.
- 새 기능을 만들 때마다 테스트를 추가하고, 휴대폰(844×390)과 태블릿(1280×800) 가로 화면에서 깨지지 않는지 확인한다.
- 이 문서와 코드가 다르면 이 문서를 따른다.

## 제품 개요

"알록달록 꼬마 놀이터"는 만 3세 아이가 숫자·색깔·모양·크기·짝 맞추기를 놀이로 배우고, 모은 코인으로 내 캐릭터와 탈것을 꾸미는 가로 화면 앱이다.

### 절대 원칙

- 현금 결제, 광고, 뽑기(가챠)는 없다. 코인은 놀이로만 모은다.
- 닉네임과 기록은 기기 안에만 저장하고 서버로 보내지 않는다. 개인정보를 URL에 넣지 않는다.
- 그림과 음악은 오리지널만 쓴다. 기존 캐릭터·작품을 따라 하지 않는다.
- 틀려도 혼내지 않는다. 오답은 "다시 찾아볼까요?"처럼 부드럽게 이끌고, 두 번 틀리면 정답이 빛난다.

| 항목 | 내용 |
|---|---|
| 대상 | 만 3세 중심 (3~4세), 글을 못 읽는 아이 기준 |
| 화면 | 가로 고정, 휴대폰·태블릿 모두 지원 (최소 높이 340 기준으로 자동 축소) |
| 플랫폼 | 안드로이드 APK, 웹(GitHub Pages, 오프라인 동작), iOS는 나중에 *(→ 위 플랫폼 변경 메모: iOS 지금 포함)* |
| 기술 | Flutter + Flame, 모든 그림은 코드로 직접 그린 오리지널 |
| 언어 | 한국어, 모든 안내는 녹음된 목소리로 읽어 준다 |

## 화면 구성과 흐름

처음 한 번 친구를 고르고 이름을 지은 뒤에는 항상 홈에서 시작하고, 홈에는 큰 버튼 세 개(놀이터 가기, 내 캐릭터, 꾸미기 상점)만 둔다.

- **놀이터:** 목록 대신 놀이터 그림. 미끄럼틀 = 숫자, 그네 = 색깔, 모래놀이터 = 모양, 시소 = 크기, 회전목마 = 짝 맞추기. 기구마다 그림 이름표와 깬 단계만큼 별이 있고, 내 캐릭터도 놀이터에 서 있다.
- **단계 고르기:** 단계 카드에 문제 그림과 계절 아이콘. 아래에는 깬 단계만큼 캐릭터가 골인 지점으로 나아가는 길.
- **놀이 화면:** 위에 멈춤 버튼·발자국 진행·코인, 가운데 문제 카드, 아래에 낮은 길과 캐릭터 말풍선.
- **내 캐릭터:** 가진 옷 입기, 가진 탈것 타기, 친구 바꾸기.
- **설정:** 눈 보호, 놀이 시간, 눈 쉬기 간격, 소리, 백업. 홈 구석의 작은 톱니바퀴 버튼으로 들어가며 부모 확인을 거친다.

## 놀이 5종 규칙

모든 놀이는 단계 5개(숫자는 8개), 한 판 5문제이고, 문제는 목소리로 내며 큰 "다시 듣기" 버튼으로 다시 들을 수 있다.

| 놀이 | 놀이터 기구 | 하는 법 | 단계가 올라가면 |
|---|---|---|---|
| 숫자 놀이 | 미끄럼틀 | 왼쪽 물건 개수를 세고 오른쪽 보기 중 맞는 숫자를 누른다 | 개수·보기 수가 늘고, 섞인 물건 중 한 가지만 세기 |
| 색깔 놀이 | 그네 | "빨간 풍선을 찾아볼까요?" 듣고 그 색 물건을 누른다 | 보기가 늘고 비슷한 색, 색 견본 없이 듣기만 |
| 모양 놀이 | 모래놀이터 | 동그라미·세모·네모·별·하트·다이아 중 찾기 | 같은 색, 회전, 견본과 같은 모양 찾기 |
| 크기 놀이 | 시소 | 같은 물건 중 큰 것/작은 것 찾기 | 3개 이상이면 "가장 큰/작은", 크기 차이가 줄어듦 |
| 짝 맞추기 | 회전목마 | 카드는 뒤집지 않고 모두 보인다. 같은 그림 두 장을 차례로 누른다 | 2→3→4→5→6쌍, 마지막은 같은 물건 다른 색 |

### 숫자 놀이 세부

- 보기에는 숫자와 함께 주사위 모양 발자국을 그려, 숫자를 모르는 아이도 모양으로 고를 수 있게 한다.
- 정답이든 오답이든 "하나, 둘, 셋…"같이 센다. 세는 소리에 맞춰 물건에 도장이 "쾅" 찍히고, 보기 자리에 큰 숫자가 뜬다. 물건은 가리지 않는다.
- 물건 색은 원색이고 단계마다 다양하게 바뀐다. 많이 나오면 줄을 맞춰 가지런히 놓는다.

**공통 흐름:** 정답 → 효과음·칭찬·코인 → 다음 문제. 한 판을 끝내면 별·코인 결과와 "또 하기 / 다음 단계 / 집으로". 다음 단계가 열리고, 단계마다 계절 배경과 음악이 바뀐다. 잠긴 단계를 누르면 카드가 흔들리며 "앞 단계를 먼저 놀아 볼까요?"라고 말한다.

## 캐릭터·꾸미기·탈것·코인

아이는 동물 친구 하나를 골라 이름을 짓고, 놀이로 모은 코인으로 옷과 탈것을 사서 꾸민다. 코인은 줄어들지 않고 틀려도 빼지 않는다.

### 친구 (24마리)

- **12지신:** 쥐, 소, 호랑이, 토끼, 용, 뱀, 말, 양, 원숭이, 닭, 개, 돼지.
- **공룡 12종:** 티라노사우루스, 트리케라톱스, 스테고사우루스, 브라키오사우루스, 안킬로사우루스, 프테라노돈, 파라사우롤로푸스, 파키케팔로사우루스, 벨로시랍토르, 스피노사우루스, 이구아노돈, 딜로포사우루스.
- 모두 같은 둥근 2등신 몸매(얼굴·턱·어깨·팔이 자연스럽게 이어짐)로 그려 옷이 다 맞는다.
- 이름 짓기에는 예시나 가짜 이름을 보여 주지 않는다. 비워 두면 랜덤 이름을 준다. 동물은 실제 이름("호랑이")으로 부른다.

### 옷 꾸미기

테마 17개(로봇, 공주, 소방관, 경찰, 군인, 원시인, 우주비행사, 의사, 요리사, 농부, 기관사, 해적, 마법사, 공룡, 히어로, 축구, 발레리나). 자리는 머리·옷·신발·장식·등 5곳이고, 아이템 71개는 10~45코인이다. 눌러서 바로 입어 보고, 살 때는 큰 ✔ / ✖ 확인 창을 띄운다.

### 탈것 7종

탈것을 고르고 "탑승!"을 눌러야 탄다. 타면 캐릭터가 옆을 보며 진짜 탄 것처럼 앉는다.

- **꾸미기:** 스티커 10종 × 원색 6가지를 "고르고 → 누르기"로 붙이고 지우개로 뗀다(드래그 없음).
- **색칠**은 탈것마다 색을 따로 산다(한 색 10코인, 처음 색은 공짜).
- 다리가 어색해 보이거나 스티커 붙일 자리가 좁은 탈것(자전거·킥보드)은 빼고 기차·열기구로 바꿨다.

| 탈것 | 가격(코인) |
|---|---|
| 열기구 | 20 |
| 기차 | 25 |
| 자동차 | 40 |
| 오토바이 | 40 |
| 탱크 | 50 |
| 비행기 | 50 |
| 우주선 | 50 |

### 코인 벌기

| 하는 일 | 코인 |
|---|---|
| 처음 시작 | 10 |
| 한 번에 맞힘 | 2 |
| 다시 시도해서 맞힘 | 1 |
| 한 판 끝내기 | 3 |
| 처음 판을 끝냄 (한 번) | 5 |
| 새 단계 처음 끝냄 | 5 |

코인이 모자라면 "놀이하면서 코인을 모아요"와 진행 막대를 보여 주고, 결제 화면으로는 절대 보내지 않는다.

## 아이 안전·건강

눈 보호, 놀이 시간, 부모 확인은 모두 기본으로 켜져 있고, 바꾸는 것은 부모님만 할 수 있다.

**부모 확인:** 설정에 들어가거나 놀이 시간을 늘리려면 덧셈 문제(각 6~9, 예: 7+8)를 숫자 패드로 풀어야 한다.

### 눈 보호 (카메라, 기본 켜짐)

- 얼굴이 화면에 30cm보다 가까워지거나(풀리는 기준 34cm), 고개를 옆으로 35°·위아래 30°·기울기 45° 넘게 돌리면 잠깐 놀이를 멈추고 "조금 더 멀리서 봐요" 같은 메시지를 띄운다.
- 잠깐 스친 것에 반응하지 않게 2~3초 이어질 때만 동작한다.
- 안드로이드는 ML Kit 얼굴 인식, 웹은 앱에 담은 MediaPipe를 쓴다. 영상은 기기 밖으로 보내지 않고 저장하지 않는다. 부모님이 설정에서 거리를 맞출 수 있다. *(→ 플랫폼 변경 메모: iOS도 ML Kit)*

### 놀이 시간

- 하루 놀이 시간 선택: 제한 없음, 10, 15, 20, 30, 45, 60분. 다 되면 "오늘은 여기까지!" 화면이 덮고, 부모 확인 후 15분 더 할 수 있다. 다음 날에 다시 풀린다.
- **눈 쉬기:** 10분 또는 20분(기본 10분) 이어서 놀면 20초 동안 "창밖 먼 곳을 봐요". 창밖 산 그림과 줄어드는 고리로 보여 주고, 끝나면 저절로 사라진다. 앱을 5분 이상 안 보면 쉬었다고 친다.

### 저장과 백업

- 모든 기록은 기기 안에만 저장하고, 저장 형식에 버전 번호를 두어 업데이트 때 안전하게 옮긴다(예: 없어진 탈것의 스티커를 새 탈것으로 옮김).
- **백업:** 설정에서 'ALOK1-'로 시작하는 글자를 복사해 두었다가 다른 기기에 붙여 넣어 복구한다. 서버는 쓰지 않는다.

## UI/UX 원칙

기준은 "글을 못 읽는 3살이 혼자서 누르고 들으며 놀 수 있는가"이다.

1. **목소리가 먼저:** 모든 문제·칭찬·안내는 말로 한다. 물건·탈것·옷을 누르면 이름을 말해 준다. 큰 노란 "다시 듣기" 버튼(62px)은 6초마다 한 번 통통 튀어 눈에 띈다.
2. **그림으로 고른다:** 놀이는 목록이 아니라 놀이터 기구 그림으로 고르고, 단계 카드에는 그 단계의 문제 그림을 그린다. 글자는 부모님을 위한 보조이다.
3. **큰 터치 칸:** 누르는 것은 최소 60~72px. 눌리면 살짝 작아지고 효과음이 난다.
4. **옆으로 밀기 금지:** 아이는 밀어서 더 본다는 걸 모른다. 목록은 화면 크기에 맞춰 칸 크기를 자동으로 골라 한 화면에 다 넣고, 너무 많으면(상점 테마 17개, 친구 12마리) 큰 화살표로 한 쪽씩 넘긴다.
5. **실수 방지:** 놀이 중 나가기는 "멈춤 → 집으로를 꾹 누르기(약 1초, 고리가 차오름)". 살 때는 ✔ / ✖ 확인. 뒤로가기 버튼은 멈춤 화면을 연다.
6. **도움은 단계적으로:** 한 번 틀리면 그림 힌트, 두 번 틀리면 정답이 빛난다. 틀린 보기는 흐려진다.
7. **어느 화면에서나:** 아이폰 노치·낮은 화면에서도 잘리지 않게 한다(높이 340 미만이면 전체 축소). 568×320, 844×390, 1280×800에서 넘침이 없어야 한다.
8. **발열을 줄인다:** 배경·캐릭터 움직임은 공용 20fps 시계 하나로 돌리고, 멈춘 장면은 그리지 않는다. 계속 도는 애니메이션을 만들지 않는다.
9. **화면 전환:** 짧은 페이드. 눈이 피로한 번쩍임·빠른 깜빡임은 쓰지 않는다.

## 아트·사운드

파스텔 배경 위에 원색 물건과 둥근 만화풍 캐릭터를 올리고, 모든 그림은 코드(CustomPainter)로 그린다.

- **배경:** 크림·하늘·민트 파스텔. 단계마다 봄·여름·가을·겨울 계절이 바뀐다.
- **물건·정답 색:** 빨강·노랑·파랑 같은 선명한 원색. 아이가 색을 헷갈리지 않게 한다.
- **캐릭터:** 외곽선 없는 납작한(flat) 파스텔 그림. 크고 둥근 머리, 짧고 단순한 원통형 몸, 점 눈·작은 코와 입·연한 볼. 머리·몸·팔·다리는 같은 색 면이 하나의 실루엣으로 이어지고(이음새 선 없음), 그라데이션 없이 색이 다른 면으로만 무늬(뿔·볏·돛·등판·꼬리·줄무늬)를 나눈다. 흰 친구(토끼·소·닭·양)만 흰 바탕에서 보이도록 실루엣 바깥에 같은 색 계열의 아주 연한 선을 둔다. 모두 같은 몸매라 옷이 공유된다.
  - *부위 음영·이음새 (사용자 피드백 "팔이 구분이 안 가", "팔·다리 연결이 레고 같다"):* 몸은 말랑한 한 덩어리 실루엣이다. 몸통은 서양배 모양(어깨 좁고 아래 둥글게, 목은 머리 아래에 숨음)이고, 아랫부분이 둥글게 좁아지며 짧고 둥근 다리 둘로 이어진다(가랑이는 둥근 U 홈, 가로 이음매 없음). 발은 둥근 콩 모양. 팔은 어깨에서 흘러나와 손끝으로 살짝 가늘어지는 둥근 소시지 모양으로, 위쪽 끝은 몸통 안에 파묻힌다. 팔은 몸과 같은 색이고, 몸 앞에 겹치는 안쪽 가장자리에만 얇고 연한 그늘을 둔다. 소매는 한 톤 진하게. 턱 아래(목 쪽 얇은 반달), 몸 오른쪽·아래 가장자리와 가랑이 안쪽에 아주 연한 단색 그늘 면을 둔다. 흰 친구는 연회색 계열로 어둡게 한다. 탑승 옆모습 팔다리도 같은 원칙(허벅지는 몸 앞쪽 아래에서 흘러나온다).
  - *변경 (2026-10-22, 사용자 결정):* 예전 "갈색 외곽선" 그림체를 위 flat 스타일로 바꿨다. 옷 71개·탈것 7종·스티커·탑승 옆모습도 같은 그림체로 그린다(탈것은 고른 원색 차체 + 파스텔 부품).
- **글꼴:** Jua(둥근 한글 글꼴), 앱에 포함.
- **음성:** 모든 문장을 미리 녹음한 mp3로 넣는다(문장 목록 → 음성 생성 스크립트). 녹음이 없는 문장만 기기 TTS로 대신한다.
- **음악:** 직접 만든 클래식풍 배경음악(첫 버전 유지, 사용자가 선호). 홈·상점·계절별 곡.
- **효과음:** 정답, 다시 해 봐요, 누르기, 코인, 팡파르, 사기, 도장 "쾅". 모두 직접 합성.

## 기술 구조와 빌드·배포

Flutter 3.x 하나의 코드로 안드로이드와 웹을 만들고, 상태는 GameState 하나가 관리한다. *(→ 플랫폼 변경 메모: iOS 포함)*

### 폴더(lib/) 역할

| 폴더 | 역할 |
|---|---|
| `core/` | 색·코인 규칙(economy.dart), 공용 20fps 시계 |
| `data/` | 단계, 아이템, 탈것, 물건 정의 |
| `character/` | 동물·공룡 그리기, 옷 입히기 |
| `vehicle/` | 탈것 그리기, 꾸미기 화면 |
| `games/` | 놀이 5종 + 공통 틀(GameFrame, 문제 타일 퀴즈) |
| `screens/`, `shop/` | 홈, 놀이터, 단계 고르기, 설정, 상점 |
| `services/` | 저장(버전 관리), 소리·음성, 눈 보호 센서 |
| `widgets/` | 버튼, 부모 확인, 놀이 시간·눈 보호 덮개, 화면에 맞는 격자 |

### 빌드·배포

- **웹:** `flutter build web --release --base-href /alokdalok/ --no-web-resources-cdn` 후 GitHub Pages 저장소(ul-dong/alokdalok)에 올린다. 서비스 워커로 오프라인에서도 열리고, MediaPipe는 앱 안에 담아 외부 CDN을 쓰지 않는다.
- **안드로이드 APK:** 맥에서 빌드 스크립트(`install_and_build.command`)로 만든다. arm 전용(armeabi-v7a, arm64-v8a)이고 ML Kit 얼굴 인식은 Play 서비스 버전을 써서 용량을 줄인다.
- **음성:** 문장 목록을 내보낸 뒤 맥에서 `gen_voice.command`로 없는 문장만 새로 녹음하고, `assets/voice`에 넣는다.
- **테스트:** 단위·위젯 테스트 142개(화면 크기별 넘침 검사 포함)를 모두 통과해야 올린다.

## 작업 규칙과 남은 일

변경은 말하지 않아도 테스트 통과 후 바로 깃허브에 올리고, 보안 문제가 없는 승인은 알아서 처리한다.

### 작업 규칙

- 비밀번호는 사용자가 직접 입력한다. 제한된 권한을 우회하지 않는다.
- 윈도우로 작업 중일 때는 깃허브(웹)에만 올리고, APK·음성 녹음은 맥이 연결될 때 한다.
- 맥에서 스크립트를 돌리는 동안에는 잠자기 모드를 막고(caffeinate), 끝나면 풀어 준다.
- 큰 변경은 미리보기 화면을 그려 확인한 뒤 올린다.

### 남은 일

- 최근 추가한 문장 음성 녹음 (맥 연결 시)
- 안드로이드 APK 빌드와 ML Kit 설정 확인 (맥 연결 시)
- 캐릭터 완전 옆모습 여부 결정 (사용자 검토 중)
- 오토바이도 다리가 보이는데 바꿀지 결정
- 연령 확장 계획: 프로필 3개, 새싹/반짝 모드, 한글·셈셈·시계·동전 놀이, 난이도 자동 조절, 계절 지도, 부모 화면, 앱마켓 정책 검토
- iOS 출시
